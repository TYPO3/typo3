:aspect:`Description`
      ..  versionchanged:: 14.2
          :changelog: feature-109126-1740000000

          Before, the default value was set with the
          :ref:`[TextEditor] <prototypes.prototypeIdentifier.formelementsdefinition.formelementtypeidentifier.formeditor.editors.*.texteditor>`.

      The default value is set with the
      :ref:`[DateEditor] <prototypes.prototypeIdentifier.formelementsdefinition.formelementtypeidentifier.formeditor.editors.*.dateeditor>`.
      It accepts an absolute date in the format `Y-m-d` or a relative date
      expression, for example `today` or `+1 day`. A relative expression
      is resolved when the form is rendered.
