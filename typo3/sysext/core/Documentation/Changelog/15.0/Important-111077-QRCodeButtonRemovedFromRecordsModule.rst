===================================================================
Important: #111077 - QR code button removed from the Records module
===================================================================

See :issue:`111077`

Description
===========

The :guilabel:`Content > Layout` and :guilabel:`Content > Records` modules
show the same records of a page in two different views. The
:guilabel:`Content > Layout` module has no QR code button, so the
:guilabel:`Content > Records` module no longer shows one next to the
:guilabel:`View webpage` button either.

The QR code of a page remains available:

*   in the :guilabel:`Content > Preview` module,
*   in the :guilabel:`Content > Publish` module (workspaces),
*   with :guilabel:`Show QR code` in the context menu of a page, for example in
    the page tree or in the record listing of the :guilabel:`Content > Records`
    module.
